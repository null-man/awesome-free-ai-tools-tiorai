"Free" on an AI pricing page usually means a fourteen-day trial, or a free tier that stops
being free the moment you try to finish something. This list only includes tools where you
can do real work without paying: a free tier that does not expire, a free plan that does not
ask for a card, or an open-source project you can run yourself.

Every entry was checked against the vendor's own pricing page at the review date below, and
the free offering is described as it actually is. Where a limit is the thing that decides
whether a tool is useful to you, the description says so instead of leaving you to find out.

Maintained by [TiorAI](https://tiorai.com/), which catalogues AI tools for a living.

## Chat assistants and answer engines

General-purpose assistants with a free tier you can use daily.

- **[Le Chat](https://chat.mistral.ai/)** — Mistral's assistant, free tier with web search and document upload, run from Europe. `Freemium` `Web` `iOS` `Android`
- **[Microsoft Copilot](https://copilot.microsoft.com/)** — Free assistant built into Windows and Edge, with image generation and web grounding included. `Freemium` `Web` `Windows` `iOS` `Android`

## How tools are selected

A tool is listed when a person can use it to finish a real task without paying. In practice
that means one of three things:

- **Free.** No paid tier that materially changes what you can do.
- **Freemium.** A free tier that does not expire, does not require a card, and is enough to
  produce something you would keep.
- **Open Source.** An OSI-approved licence, so you can run it yourself. Source-available is
  not open source, and products in that position are described as source-available in prose
  rather than given the label.

What does not qualify, however good the product is: a time-limited trial, a credit-limited
trial that expires, a free tier gated behind a credit card, a waiting list, a closed beta, or
a "contact sales" page standing in for pricing. A trial is a sales mechanism, not a free
tier, and a list that conflates the two is useless to the person reading it.

Free tiers get cut. When a listed tool moves to paid-only, it is removed rather than quietly
relabelled, and the change is recorded in [CHANGELOG.md](CHANGELOG.md).

Entries are ordered alphabetically inside each category. Position carries no meaning, and
there is no paid placement, sponsorship, or affiliate link anywhere in this repository.
